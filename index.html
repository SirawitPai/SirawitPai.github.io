04 / TESTING

Shipping is half the job.
Proving it works is the other.

I look at every feature from both sides — how it's built, and how it could break.

On the web side I write unit tests in Jest on most projects, and I test APIs with Postman — status codes, responses and error cases. I've also done functional, non-functional, integration, regression and UAT testing, with basic Cypress automation for key flows. Knowing the code behind the screen helps me find root causes faster and write bug reports developers can act on right away.
